Research Projects

ONLINE SELECTIVE INFERENCESep 2026 – Present

Online Selective Classification with Expert Review

Advisor: Prof. Wenguang Sun

Studying sequential binary classification in which a model can predict either class or abstain, while expert labels are observed only for cases the model reports. The project examines how to improve the classifier under this selective feedback while controlling the false selection rate (FSR).

  • Exploring when to request labels from less certain regions so the model can learn beyond previously reported cases.
  • Designing comparisons with full-feedback and fixed-model baselines to evaluate error control, reporting volume, and the number of correct decisions.
EMBODIED INTELLIGENCEMar 2026 – Present

Dynamic-Evolution Mixture-of-Experts
Vision-Language-Action Models

Student Research Training Program (SRTP) · Advisor: Prof. Zemin Liu

Exploring a MoE-VLA architecture that connects vision-language understanding, task routing, and skill-expert execution to improve the efficiency and generalization of embodied agents.

  • Investigating proactive lifelong learning through task execution, data accumulation, structural optimization, and model iteration.
  • Designing a hierarchical library of atomic and composite skills, with autonomous expert splitting and merging based on interaction trajectories.
